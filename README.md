# OMRI DRUMS

אתר תיק עבודות לעמרי, מתופף. אתר סטטי (HTML, CSS, JavaScript), מותאם לנייד.

## איך מעדכנים תוכן
כל התוכן נמצא בקובץ אחד: **`content.js`**.
טקסטים, הופעות, סרטוני יוטיוב, תמונות ופרטי קשר. לא צריך לגעת בשום קובץ אחר.

- **הופעות**: מוסיפים שורה עם תאריך בפורמט `2026-12-31`. האתר מחלק לבד לקרובות וקודמות.
- **יוטיוב**: מדביקים רק את המזהה של הסרטון (מה שבא אחרי `watch?v=`).
- **תמונות**: שמים בתיקייה `images/` ומעדכנים את הנתיב. שדה ריק מציג מקום שמור מעוצב.

## העלאה לאוויר (GitHub Pages)
1. בריפו ב-GitHub: Settings > Pages
2. Source: Deploy from a branch
3. Branch: `main`, תיקייה `/ (root)`, Save
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת שמופיעה שם

## צפייה מקומית
פותחים את `index.html` בדפדפן, וזהו.
